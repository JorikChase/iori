The page has no visible header (iori will write one later): `<header class="head">` is empty and
hidden while empty; a screen-reader-only `<h1>` remains.

Defaults iori chose: **Outfit Bold** (body 600 / titles 500 / captions 700), Blade Runner 2049 look
(night = warm black + sodium amber, dust = light), oldest first from 4.12.2003, desktop decides UX.

Live sources: embeds/pages wake after 60 % in view for 500/900 ms; running budget 2 players + 1 page
(touch: 1 player, pages on tap); out of view they pause and hide, the two most recent stay loaded; the last
ten static items stay decoded. Auto-woken players never autoplay; a newcomer never evicts a running frame.

## Privacy rules (do not break)

- `.readme` (the memoir) is gitignored and deploy-excluded. **No memoir text, names or places in the repo**:
  the repo is public. Tools read the memoir at run time; `tools/timeline/privacy.json` holds only hashes.
- Visibility policy (iori, 2026-10-14): everything public **except the most intimate**: the 24 entries
  listed in `privacy.json` stay private (they include the last chapter's title, which names the current
  home). `apply_visibility.py` applies it; hand-set visibility is kept unless `--all`.
- Private and undated entries never reach the published files. Check after any publish (see the scan in
  the plan file, or grep the year files for a few private words).

  && cp -f server_setup.sh /tmp/server_setup.sh && bash /tmp/server_setup.sh'

SSH to the VPS sometimes resets during the key exchange: retry after a few seconds.
Bump the `?v=` numbers in `timeline.html` (css, js) and the imports inside `timeline.js` when files change.

## Gotchas learned

- Changing only the `#` does not reload a page: use `location.reload()` when testing.
- The hidden Browser pane pauses requestAnimationFrame and IntersectionObserver; drive wake/scroll tests
  with Playwright (`tools/timeline/test/`).
- The preview launcher cannot read ~/Desktop: run local servers from a shell.
- `.page` was the layout wrapper class and also a kind class: the wrapper is `.tl-page` now. Kind names
  are classes on items; do not reuse them for layout.
- `html { overflow-x: clip }` with `body { overflow-x: hidden }` unsticks sticky elements: use clip on both.
- Page screenshots: SwiftShader wedges on heavy WebGL; run `page_posters.mjs --gpu`, one page per process
  under a hard time limit, selecting pages with `--exact <address>` (`--only /` matches every page, because
  the two landing pages' path is just "/").
- Meta's exports mis-encode UTF-8 (fixed in `import_instagram.py`); iPhone originals are HEIC (converted
  with `sips` in `import_gphotos.py`).
