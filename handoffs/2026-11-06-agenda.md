## A. Lens (`~/Desktop/code/lens`, one commit "lens mvp", Feb 2026)

**What it is.** A full-screen, always-on-top Metal overlay (1561 lines of `Lens.mm` + `Shaders.metal`).
ScreenCaptureKit streams the display (own window excluded); the fragment shader unions rounded-box SDFs
with a smooth-min, turns distance into a height profile (softness, slope, min/max levels), and uses the
height gradient to offset the screen sample per colour channel (refraction + dispersion), plus a gloss
term and a fixed 1.2 saturation boost. A paint mode accumulates a height map from point sprites
(additive brush, reverse-subtract eraser). A Cocoa-drawn "brutalist white" HUD shows keys and a slope
gradient with three draggable handles. The Feb screenshots show it used mostly as a **painted liquid
distortion**, not as a tidy Tahoe glass panel.

**Diagnosis — the glass.**
- The refraction is a 2-D gradient displacement, not a lens: no thickness model, no Snell term, no
  magnification inside the plateau (real Liquid Glass slightly magnifies and shows a bright rim).
- No backdrop blur/frost, no Fresnel rim, no inner shadow, no drop shadow, no adaptive tint by
  backdrop luminance. Dispersion and refraction strengths are constants in the shader.
- The height map is re-rasterised from *every* stroke every frame (cost grows with painting).
- `getLensHeight` is evaluated four times per fragment for the gradient (centre + two taps + map).

**Diagnosis — engineering.**
- `Shaders.metal` is read from the working directory at runtime; no `.app` bundle, no icon, no menu
  bar item, no Cmd+Q path except Esc/Terminal.
- Mouse pass-through is a 20 Hz `NSTimer` poll toggling `ignoresMouseEvents`; mode model is three
  overlapping flags (overlay / edit / paint) and TAB, P, E, H, X, 1–3, Cmd±, Shift±, Cmd[] — nothing
  on screen explains when a click goes through to the desktop.
- No persistence (lenses vanish on quit), no delete-one-lens (X clears all), no z-order, no
  duplicate, single display only, `windowNumber` exclusion assumed valid before the window exists.

**Proposed work (mine).**
1. Glass v2 shader: analytic rounded-box SDF normal, thickness profile → true `refract()` with per
   channel IOR, mip-blurred backdrop by thickness, Fresnel rim + inner shadow + soft drop shadow,
   luminance-adaptive tint; keep the painted height map as a second layer. Expose strengths in the HUD.
2. Height map kept as a persistent texture (strokes drawn once, undo via stroke list replay only
   when needed).
3. App shell: `.app` bundle with the shader in Resources (or precompiled metallib), menu-bar status
   item with the key map, Backspace deletes the hovered lens, lens set saved to
   `~/Library/Application Support/Lens/`.
4. Pass-through without polling: a transparent window per lens *or* `NSWindow` hit-testing via
   `-[NSView hitTest:]` returning nil off-lens.

## B. Feedback (`~/Desktop/code/feedback`, "Velocity Glitch", Jan 2026)

**What it is.** One SDL2 file (567 lines): a borderless, transparent, always-on-top 128×128 window
running a decaying Game of Life whose history buffer is re-drawn zoomed each frame — a video-feedback
tunnel. LMB paints, RMB erases, drag adds velocity to the tunnel, ↑/↓ zoom speed, Space pause, Esc quit.

**Why it cannot be sent today.**
- The binary links `/opt/homebrew/opt/sdl2/lib/libSDL2-2.0.0.dylib` — it will not launch on another Mac.
- Not a `.app`: no icon, no Dock entry, no Cmd+Q, no menu; Gatekeeper will refuse an unsigned
  download ("damaged") unless the recipient right-click-opens or strips quarantine.
- Nothing on screen says what the keys do; the window cannot be moved (dragging is the tunnel's
  velocity); fixed `srand(12345)`.

**Proposed work (mine).**
1. `.app` bundle with SDL2 bundled inside (static link or `SDL2.framework` in `Contents/Frameworks`
   with `@rpath`), `Info.plist`, icon, `Cmd+Q`, Option-drag moves the window, a first-run key overlay
   that fades, a `build.sh`.
2. Signing: ad-hoc signature + zip + a one-line "right-click → Open" note, **or** Developer ID +
   notarization if iori has a paid Apple developer account (decision needed).
3. Optional: a Windows build (SDL2 is portable; the Cocoa transparency helper is the only Mac part).
