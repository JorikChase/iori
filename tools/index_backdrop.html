index.html backdrop

Prints the linear-gradient that index.html paints before WebGL has a context. Run it whenever assets/3dieMainBckg.hdr, the camera, or the post-processing chain changes, and paste the result into the --backdrop custom property.

It has to measure rather than model. index.html draws through an EffectComposer whose final pass writes its linear render target straight to the canvas, so the page shows up roughly 40% darker than the same scene through a plain renderer.render(). Any gradient derived from the HDRI alone comes out far too bright, which is glaring in the moment before the canvas fades in. So this page reproduces index.html's exact renderer, camera and pass chain, and reads back what the user will actually see.
