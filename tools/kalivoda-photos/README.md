## The old Glitch site

Glitch is gone: every glitch.com route redirects to its blog, and project downloads
ended on 31 December 2025. ArchiveTeam's July 2025 rescue did save public project
metadata and many uploaded files, and those are in the Wayback Machine.
`tools/glitch-recover.py <project-name>` pulls them back (tested on kucharkybezdomova:
22 of its uploads recovered at full size). iori's Glitch login was JorikChase, but no
list of that account's projects was archived, so the Kalivoda project's name (the
part before .glitch.me) is needed.
